# Note Taking Site — Backend

Веб-приложение для ведения заметок с ролями, черновиками, корзиной и админ-панелью.
Реализовано на Spring Boot с серверным рендерингом Thymeleaf.

## Схема БД

Две таблицы, связь один-ко-многим (User → Notes).

**users**
| Колонка | Тип | Ограничения |
|---|---|---|
| id | bigint | PK, auto increment |
| email | varchar(255) | NOT NULL, UNIQUE |
| password | varchar(100) | NOT NULL (BCrypt hash) |
| role | enum('ADMIN','USER') | NOT NULL |
| created_at | timestamp | NOT NULL |

**products** (заметки)
| Колонка | Тип | Ограничения |
|---|---|---|
| id | bigint | PK, auto increment |
| name | varchar(120) | NOT NULL |
| description | varchar(10000) | |
| status | enum('ACTIVE','DELETED','DRAFT') | NOT NULL |
| author_id | bigint | NOT NULL, FK → users.id |
| created_at | timestamp | NOT NULL |
| updated_at | timestamp | NOT NULL |

Связь: `products.author_id → users.id` (ManyToOne).

## Роли и права

- **USER** — работает только со своими заметками: CRUD, черновики, корзина.
- **ADMIN** — дополнительно: список всех пользователей, смена ролей, удаление пользователей, просмотр всех заметок, удаление любых заметок.
- Публично доступны: `/`, `/login`, `/register`, `/h2-console`.
- Всё остальное — после аутентификации.
- `/admin/**` — только роль ADMIN.

Статика (Bootstrap через CDN) подгружается с внешнего ресурса и не требует разрешений на бэкенде.

## Запуск

```bash
# из корня проекта
mvn spring-boot:run
```

Приложение стартует на `http://localhost:8080`.

**H2-консоль:** `http://localhost:8080/h2-console`
- JDBC URL: `jdbc:h2:mem:notesdb`
- User: `sa`
- Пароль: (пусто)

## Seed-аккаунты

Создаются автоматически при первом старте (`DataInitializer`):

| Email | Пароль | Роль |
|---|---|---|
| admin@example.com | admin123 | ADMIN |
| user@example.com | user123 | USER |

## Валидация

Два уровня:
1. **DTO + Bean Validation** (`@Valid` в контроллере, `@NotBlank`, `@Size`, `@Email`) — ошибки ловятся до вызова сервиса, возвращаются на форму.
2. **Ограничения схемы БД** (`@Column(nullable = false, length = ...)`) — защита целостности данных.

## Обработка ошибок

Централизована в `GlobalExceptionHandler` (`@ControllerAdvice`):

| Исключение | HTTP | Страница |
|---|---|---|
| `NoteNotFoundException` | 404 | error/404 |
| `UserAlreadyExistsException` | 409 | error/409 |
| `IllegalArgumentException` | 400 | error/400 |
| `Exception` | 500 | error/500 |

## Логирование

SLF4J + Logback. Уровни:
- **INFO** — успешные операции (регистрация, создание/обновление/удаление заметок, действия админа, seed-пользователи).
- **WARN** — ожидаемые бизнес-ошибки (заметка не найдена, email занят, ошибка валидации).
- **ERROR** — неожиданные исключения со стектрейсом.

## API (эндпоинты)

### Публичные

| Метод | URL | Что делает |
|---|---|---|
| GET | `/login` | Страница логина |
| POST | `/login` | Аутентификация (обрабатывает Spring Security) |
| GET | `/register` | Страница регистрации |
| POST | `/register` | Регистрация (`@Valid RegisterRequest`) |
| POST | `/logout` | Выход |

### Заметки (USER, ADMIN)

| Метод | URL | Что делает |
|---|---|---|
| GET | `/products` | Активные заметки текущего пользователя |
| GET | `/products/drafts` | Черновики текущего пользователя |
| GET | `/products/trash` | Корзина текущего пользователя |
| GET | `/products/add` | Форма создания |
| POST | `/products/add` | Создать заметку (`@Valid NoteRequest`) |
| GET | `/products/{id}` | Просмотр заметки |
| GET | `/products/{id}/edit` | Форма редактирования |
| POST | `/products/{id}/edit` | Обновить заметку |
| POST | `/products/{id}/trash` | Переместить в корзину (soft delete) |
| POST | `/products/{id}/restore` | Восстановить из корзины |
| POST | `/products/{id}/draft` | Перевести в черновик |
| POST | `/products/{id}/delete` | Удалить навсегда (physical delete) |

### Админ (ADMIN)

| Метод | URL | Что делает |
|---|---|---|
| GET | `/admin/users` | Список пользователей |
| POST | `/admin/users/{id}/role` | Сменить роль (параметр `role`) |
| POST | `/admin/users/{id}/delete` | Удалить пользователя |
| GET | `/admin/notes` | Все заметки (опциональный параметр `status`) |
| POST | `/admin/notes/{id}/delete` | Удалить любую заметку |

## Безопасность

- Пароли хранятся в виде BCrypt-хеша, не в открытом виде.
- CSRF-токен обязателен во всех POST-формах (Thymeleaf подставляет автоматически при `th:action`).
- Проверка авторства: пользователь работает только со своими заметками (`findByIdAndAuthor`).
- Роли разграничивают доступ к `/admin/**`.
- JPA защищает от SQL-инъекций (параметризованные запросы).
- Валидация на входе и на уровне схемы БД.

## Разделение ответственности

- `controller` — приём запросов, валидация DTO, возврат шаблона.
- `service` — бизнес-логика, проверка прав, транзакции.
- `repository` — доступ к данным.
- `model` — сущности БД, без логики представления.
- `dto` — данные для обмена между фронтом и беком.

Бэкенд не занимается представлением (HTML, CSS, Bootstrap — зона фронтенда), фронтенд не содержит бизнес-логики.
